# Student Performance Analysis and Early Risk Detection System

## 🎯 About the Project
A final year B.Tech CSE project developed at RKGITM Ghaziabad.

This system analyzes student academic data across 4 parameters 
and classifies each student into a risk zone — helping faculty 
identify at-risk students BEFORE the semester ends.

## 🚦 Risk Classification
Each student gets a weighted score based on:
| Parameter | Weight |
|---|---|
| Previous Semester SGPA | 30% |
| Attendance | 25% |
| Internal Marks | 25% |
| Assignments Submitted | 20% |

🟢 Green (Safe) → Score ≥ 70%
🟡 Yellow (Moderate Risk) → Score 45–70%
🔴 Red (High Risk) → Score < 45%

## 🛠️ Tech Stack

- CSV — Data input format
